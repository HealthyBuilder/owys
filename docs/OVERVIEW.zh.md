# Owys 功能说明

> Spend at a company, own a piece of it.
> 一张虚拟卡，每笔消费返 3%，返的不是现金，是**你刚刚消费的那家公司的代币化股票**，直接进你自己控制的钱包。

本文说明当前这个 PoC **实现了什么**、**每个功能是干嘛的**，以及**哪些是真的、哪些是模拟的**。
技术实现见 [ARCHITECTURE.zh.md](ARCHITECTURE.zh.md)。

---

## 一分钟理解

```
刷卡  →  认出这是哪家公司  →  按 3% 记一笔返点（上链）
      →  按股票批量换汇   →  股票进你自己的钱包
```

关键在于**卡原生**：不需要拍小票、不需要转发确认邮件、不需要人工审核。刷卡授权流直接触发，自动识别商户，秒级完成，全程跑在 Solana 上。

## 界面：四个页面 + 一个 Protocol

导航是 **Card · Portfolio · Activity · Simulate**，右上角另有一个刻意做淡的 **Protocol**。

### 1. Card — 持卡人看到的全部

一列居中：卡片 → 三行数据。

| 元素 | 含义 |
| --- | --- |
| **Available to spend** | 卡内可用余额。这张卡是**预付**的，余额不足会被**拒付** |
| **Total spent** | 累计消费额与笔数 |
| **Equity earned** | 累计获得的股权价值，以及分散在几家公司 |
| **Awaiting conversion** | 已记账但还没换成股票的金额（周末、或未达批量阈值时会有余额） |
| Top up / New cardholder | 充值 $1,000 / 新建一个持卡人 |

**为什么余额是重要的**：它不是装饰。超过余额的授权会被真的拒绝、不返点、在 Activity 里划线显示 Declined。这让 webhook 真的返回 approve/decline 决策，而不是永远 approve —— 那才是真实发卡商集成要求的形状。

### 2. Portfolio — 你的消费画出来的持仓

- 组合总市值 + 配比环形图
- 每个持仓标注 **代币符号 · 发行方**，例如 `NKEon · Ondo Global Markets`
- **Claim** 按钮：把程序托管的代币提到你自己的 ATA（关联代币账户）

Claim 这一步是整个产品的核心主张 —— 提完之后那些股票代币在**只有你能控制的钱包里**，不是平台的账面数字。

### 3. Activity — 交易记录，以及「为什么是这只股票」

每条交易显示：商户原始描述、金额、返点、换成了哪个代币、来自哪个发行方。

**点开任意一条**，会展开解析器的完整推理过程：

```
raw "STARLINK INTERNET" (MCC 4899 · Cable / Streaming)
normalized -> "STARLINK INTERNET"
stage 2 brand_exact "STARLINK" -> Starlink (MCC corroborates)
  listed parent: Space Exploration Technologies (SPCX)
  note: SpaceX is private and unavailable in any brokerage account —
        but a tokenized SPCX exists onchain.
  settling in SPCX via Sunrise
```

这块刻意放在交易详情里、而不是单独做一页：**用户无法追问的返点，只能靠信任接受**。让 demo 有说服力的内容，和让产品可信的内容，是同一块内容。

### 4. Simulate — 模拟刷卡

35 个真实形态的商户描述符，点一下就发一笔授权。每条下面写了它在演示什么（比如「处理商前缀不剥掉，返点就记到 PayPal 头上」）。

**为什么单独做一页**：这是整个产品里唯一在生产环境**不存在**的部分。拆走之后，Card 页看到的就是真实持卡人会看到的东西，不掺演示脚手架。

### Protocol — 你问的那个按钮

放在右上角、颜色做淡，因为**持卡人不需要它**。它是给你、给工程师、给尽调方看的「掀开盖子」页面，证明前面三页不是假的。里面有四块：

| 区块 | 内容 | 为什么有用 |
| --- | --- | --- |
| **Deployment** | 集群、程序地址、Config PDA、金库地址、返点费率（bps）、链上累计 accrual 笔数、累计消费/记账/结算金额、缓存商户数、批量阈值 | 程序地址可以点开 Solana Explorer —— 任何人都能自己验证链上状态，不用信我们的界面 |
| **Issuers** | 三家发行方各有多少标的 | 这个产品的覆盖率直接由它决定（见下文） |
| **How spend resolved — by dollar** | 消费额按解析阶段的分布条形图 | 一眼看出多少钱精准命中了具体公司、多少钱降级了。这是产品健康度的核心指标 |
| **Settlement batches** | 每批换汇的明细、成交价、上链条数；以及「Settle pending now」手动触发 | 证明返点是**批量**换汇的（每个股票一笔交易，不是每次刷卡一笔），这是 3% 返一杯咖啡在经济上成立的前提 |

## 三个技术亮点

### 一、商户识别：脏字符串 → 上市母公司

卡组织给你的是这种东西：`SQ *BLUE BOTTLE COFFEE`、`TST* CHIPOTLE 2841`、`PAYPAL *NIKESTORE`、`WHOLEFDS MKT #10255`。

六级解析阶梯，置信度从高到低：

| 级别 | 机制 | 置信度 |
| --- | --- | --- |
| 1 | **network_id 缓存** —— 这个商户见过，永久记住 | 1.00 |
| 2 | 品牌精确匹配 | 0.90–0.98 |
| 3 | 品牌模糊匹配（容错拼写/截断） | ≤0.85 |
| 4 | **代理敞口** —— 品牌未上市，用最接近的上市公司 | ≤0.55 |
| 5 | 最接近的篮子（科技类消费 → QQQ） | 0.40 |
| 6 | 大盘兜底（SPY） | 0.20 |

第 1 级是长期护城河：命中率随交易量单调上升，永不衰减。

**商户表里最有价值的是「品牌 ≠ 上市主体」的那些**：

- `WHOLEFDS MKT` → 亚马逊（2017 年被收购，按品牌名查什么都查不到）
- `GEICO *AUTO PREMIUM` → 伯克希尔（一笔车险保费买到 BRK.B）
- `DQ GRILL` → 也是伯克希尔（两个毫不相干的描述符，同一个标的）
- `KFC` / `TACO BELL` / `PIZZA HUT` → 同一个 YUM
- `MARSHALLS` / `HOMEGOODS` → 同一个 TJX
- `DUNKIN` → 2020 年被私有化，**真的没有股票可以给**
- `STARLINK` → SpaceX，私有公司，**任何券商账户里都买不到，但链上有 SPCX**

最后一条是传统金融结构上做不到的事，也是这个 demo 最强的一幕。

### 二、多发行方聚合

Solana 上的代币化股票不是一个统一市场，而是分散在几家发行方手里，各有各的清单和命名规则：

| 发行方 | 规模 | 符号 | 特点 |
| --- | --- | --- | --- |
| **xStocks**（Backed） | ~55 股 + 4 ETF | `AAPLx` | 指数型：医药、金融、企业软件为主，**几乎没有消费品牌** |
| **Sunrise**（联合 Backpack） | 20 个 | `COST` | 小而准，是拿到 `SPCX`（SpaceX）的唯一途径 |
| **Ondo Global Markets** | 200+ | `NKEon` | 数量最大，补上前两家缺的消费品牌 |

**这件事的价值有多大，实测过：**

| 结算方案 | 能买到的比例 |
| --- | --- |
| 只接 xStocks | **37%** |
| 三家都接 | **80%** |

同一个解析器、同一张商户表、同样 35 个样本，**唯一变量是接了几家发行方，触达翻倍**。

原因是解析器从来不是瓶颈 —— 两种配置下它都能认出 **33/35（94%）** 的上市母公司，变的是能不能**买到**。xStocks 缺的全是 `NKE / SBUX / COST / UBER / TGT / CMG` 这类卡真正天天刷的品牌。

> **结论：约束在发行方的标的清单，不在商户匹配。** 在匹配算法上花一个月，不如花一天做多发行方路由。

三家全接完还剩 5 个缺口，且都是真正不可解的：雀巢（只有 ADR，没有发行方做 ADR）、Dunkin'（私有化）、Trader Joe's（私有）、无名熟食店、政府缴费。**ADR 是唯一还能解的**，这是可以拿去找 Backed / Ondo 的具体诉求。

### 三、返点上链，且不可重放

每笔返点在链上记一条 `Accrual`，账户地址由**卡交易 ID** 推导。卡组织重复投递 webhook 是常态，第二次会直接创建失败 —— **防重放做在链上，不在应用层**。

另外，记账的密钥**永远动不了代币**。webhook 服务被攻破只能造假「索赔记录」，造不出假股份。

## 现在是真的 vs 模拟的

这一栏是这份文档最重要的部分。

| | 状态 |
| --- | --- |
| 链上程序、PDA、防重放 | **真** —— 已部署 devnet |
| 代币托管、Claim 进用户自己的 ATA | **真** SPL 转账 |
| 每用户持仓、链上累计消费/返点 | **真** 程序状态 |
| 商户解析管道 | **真** 逻辑，生产形态 |
| 发行方清单与归属 | **真** 清单（Ondo 部分是代表性子集） |
| 返点算术（整数微美元、向下取整） | **真**，与链上逐位一致 |
| 股票代币 | **模拟** —— 101 个真实标的的 mock mint，真代币只在主网 |
| 换汇 | **模拟** —— 固定报价；生产用 Jupiter |
| 价格 | **模拟** 报价；生产用 Pyth |
| 刷卡授权 | **模拟** 生成器，Stripe Issuing 形态 |
| 卡余额与拒付 | **模拟**余额，但真的会拦截授权 |
| 持卡人钱包 | 本地密钥对；生产用 Privy / Turnkey |
| 链上 USDC 消费金库 | **未实现** —— 余额只在链下 |

## 三个必须正视的现实约束

不是以后再解决的障碍，是决定产品形态的前提。

**1. 3% 平返在任何发卡经济学下都是亏的。**
借记卡 interchange 只有 0.2%–1.2%，信用卡 1.5%–2%。可行结构是：基础 ~1%（interchange 支撑）+ 品牌自费 2%–8%（走 card-linked offer / 联盟网络）。本 PoC 用补贴池硬编码 300 bps。懂支付的人第一个问题就是这个。

**2. xStocks 和 Ondo 都明确排除美国人。**
所以代币结算的卡**不能美国首发**。现实起点是拉美（Rain 已经支撑 MoneyGram 在哥伦比亚的稳定币 Visa 卡）或东南亚。要做美国版是另一个产品：券商碎股合作，或 Superstate Opening Bell 那种真正注册在链上的股份。

**3. 用证券做返利本身是证券分发行为**，不是 cashback。赠与还是销售、是否触发招股说明书义务、有没有 broker-dealer 豁免，在任何用户资金进来之前都需要真实答案。

## 怎么跑

```bash
cd ~/solana/equity-back
pnpm install
pnpm mint-tickers     # 101 个 mock 标的，可断点续跑
pnpm run init-config  # 初始化 Config PDA，300 bps
pnpm server           # 打开 http://127.0.0.1:4000
```

另外两个有用的命令：

```bash
pnpm demo             # 命令行完整跑一遍，每步打印 Explorer 链接
pnpm resolver-report  # 解析覆盖率报告，不碰链，调商户表时用这个
```
